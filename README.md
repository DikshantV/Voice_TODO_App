# Voice_TODO_App
Voice TODO list web app with NLP

## To clone this repo:

`git clone https://github.com/DikshantV/Voice_TODO_App.git`

## How to run it locally:
### Install necessary packages:

    openai>=1.12.0
    httpx>=0.25.0
    streamlit>=1.28.0
    python-dotenv>=1.0.0
    deepgram-sdk>=1.3.0

### or run:

    `pip install -r requirements.txt`

### Environment variables (api_keys):

    DEEPGRAM_API_KEY = "your_deepgram_api_key"
    OPENAI_API_KEY = "your_openai_api_key"

### run the app:

    `streamlit run app.py`
